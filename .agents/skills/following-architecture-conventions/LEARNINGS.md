- [2026-07-28][source:inference][task:dev-mode][probation] The "lower layers never import upper layers" rule has ONE established exception: run DRIVERS living in `lib/` may import `orchestrator/`. Precedent is `src/lib/run-many.ts` (imports Orchestrator + GlobalScheduler); `src/lib/dev-mode/dev-driver.ts` follows it. The test is whether the module ORCHESTRATES runs (a driver) rather than being consumed BY the orchestrator — everything below a driver (planner, compiler, prompt blocks) must stay pure and importable from anywhere.
- [2026-08-04][source:inference][task:devgraph-schema-split][probation] When the consumer of a parsed format is a VISUAL EDITOR, split validation as "zod = SHAPE / validator = PRODUCT LIMITS" and give every cap exactly one owner. Precedent: `graph-schema.ts` asks only "is this a devgraph at all" (types, enum membership, plus DoS ceilings an order of magnitude ABOVE the product caps), while `graph-validate.ts` owns every limit the human is meant to feel (40 nodes, 80-char labels) and every referential rule. The reason is asymmetric cost: a parse error is a BLANK CANVAS and the human loses their drawing, whereas an issue is a to-do they can fix on screen. Corollary from the same file: a DECLARATION (graph id, choice id, outcome id) is strict in the schema, a REFERENCE (node id, edge source/target, `fanOutFrom`) is permissive there and checked by the validator — references are what a human breaks by deleting a node, and that deserves a sentence, not a refusal to open.
- [2026-08-04][source:inference][task:devgraph-client-types][probation] In `src/web/client/**/*.js` under `tsconfig.client.json` (`allowJs` + `checkJs` + `strict: false`), a JSDoc DISCRIMINATED UNION does not narrow reliably across an `if (!v.ok)` boundary — `strict: false` disables the control-flow analysis the narrowing depends on. The house answer is a single LOOSE shape plus prose in the JSDoc explaining the two states (see `GraphVerdict` in `client/modules/graph/graph-model.js`: `{ ok: boolean, code?: string, message?: string }`), NOT a union that typechecks in the server tsconfig and silently stops narrowing here. Same file states the companion rule: the strict declarations live in `src/lib/dev-graph/graph-types.ts` and the SERVER enforces them; a client typedef that pretended a wire payload is well-formed would only move the lie earlier.
